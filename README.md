# Al-Janah Al-Abyad Dental Center

A responsive Arabic (RTL) landing website for a dental and implant center in Riyadh, Saudi Arabia, presenting the center's services and an easy way to book an appointment.

**Live demo:** https://salmantawfeeq.github.io/AL-JANAH-AL-ABYAD-DENTAL-CENTER/

## Highlights

- Arabic-first, right-to-left layout that adapts to mobile, tablet and desktop
- Sections for services (implants, cosmetic dentistry, orthodontics), about and contact
- SEO-ready page title and meta description
- Lightweight static site with no build step

## Tech Stack

HTML5, CSS3, vanilla JavaScript, deployed on GitHub Pages.

## Run Locally

Open `index.html` in a browser, or serve the folder with any static server.
